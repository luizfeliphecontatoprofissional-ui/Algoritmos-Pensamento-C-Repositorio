## Exercícios de Programação em C

Repositório criado para reunir exercícios e práticas de programação em linguagem C, desenvolvidos durante os estudos de Algoritmos e Pensamento Computacional.

Os exercícios estão organizados em pastas de acordo com cada lista, facilitando a consulta e o acompanhamento da evolução.

## Conteúdo

# Lista-1:

Exercícios introdutórios de algoritmos e lógica de programação, trabalhando conceitos como:

Entrada e saída de dados
Operações matemáticas
Estruturas condicionais
Operadores lógicos
Tomada de decisão

# Lista-2:

Exercícios voltados principalmente para vetores e estruturas de repetição, incluindo:

Laços de repetição
Percurso de vetores
Soma e média de elementos
Contagem de valores
Busca de elementos
Maior e menor valor
Posições e valores repetidos

# Exercicios-Aula08:

Exercícios de prática de programação envolvendo:

Laços de repetição
Vetores
Matrizes
Funções
Exercícios e desafios
Objetivo


# Organização

Praticar os fundamentos da programação em C, desenvolver a lógica de programação e consolidar os conceitos apresentados durante as aulas.

Os exercícios são desenvolvidos individualmente como parte do processo de aprendizagem.

Cada pasta contém os códigos referentes à sua respectiva lista de exercícios.

Este repositório será atualizado conforme novos exercícios forem desenvolvidos.
