## Exercícios de Programação em C

Repositório criado para reunir exercícios e práticas de programação em **linguagem C**, desenvolvidos durante os estudos de **Algoritmos e Pensamento Computacional.**

Os exercícios estão organizados em pastas de acordo com cada lista, facilitando a consulta e o acompanhamento da evolução.

## Conteúdo

# Lista-1:

Exercícios **introdutórios** de algoritmos e lógica de programação, trabalhando conceitos como:

Entrada e saída de dados

Operações matemáticas

Estruturas condicionais

Operadores lógicos

Tomada de decisão

# Lista-2:

Exercícios voltados principalmente para **vetores e estruturas de repetição**, incluindo:

Laços de repetição

Percurso de vetores

Soma e média de elementos

Contagem de valores

Busca de elementos

Maior e menor valor

Posições e valores repetidos

# Lista-3:

Exercícios de **aprofundamento** em programação em C, trabalhando principalmente conceitos como:

Vetores e processamento de dados

Matrizes e operações com dados bidimensionais

Funções e modularização do código

Structs e organização de registros

Ponteiros e manipulação de endereços de memória

Integração dos conteúdos em desafios práticos e sistemas completos

# Exercicios-Aula08:

Laços de repetição

Vetores

Matrizes

Funções

Exercícios e desafios com os assuntos anteriores reunidos.

# Defesas-de-codigos:
**A2-1:**
Desenvolvimento de um sistema para resolver um **problema real**, trabalhando conceitos como:

Estruturas condicionais

Laços de repetição

Vetores

Busca de elementos

Processamento de dados

**A2-2:**
Continuação e **evolução** da proposta anterior, acrescentando novos conceitos e funcionalidades, incluindo:

Modularização com funções

Structs e vetores de structs

Manipulação de arquivos

Leitura e gravação de dados

Recuperação de registros anteriores

Integração dos conceitos estudados anteriormente

As atividades também envolvem a defesa individual do código, exigindo conhecimento sobre a estrutura, o funcionamento e a implementação do projeto.

# Organização

Praticar os fundamentos da programação em C, desenvolver a lógica de programação e consolidar os conceitos apresentados durante as aulas.

Os exercícios são desenvolvidos individualmente como parte do processo de aprendizagem.

Cada pasta contém os códigos referentes à sua respectiva lista de exercícios.

Este repositório será atualizado conforme novos exercícios forem desenvolvidos.
